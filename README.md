# StudyMate AI - RAG Powered Document Assistant

StudyMate AI is an intelligent document question-answering assistant powered by Retrieval-Augmented Generation (RAG). It allows users to upload documents and interact with them through a conversational AI interface.

The system retrieves relevant information from user-provided documents and generates accurate responses using Large Language Models (LLMs).



## Features

- 📄 Supports multiple document formats:
  - PDF
  - DOCX
  - TXT
  - Web pages

- Semantic document search using vector embeddings

- Chat-based question answering

- Context-aware responses with conversation memory

- Scalable knowledge base using ChromaDB
